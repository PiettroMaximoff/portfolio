# Frontend Developer

Portfolio of a frontend developer with 5 years of commercial experience. I build interfaces and client-side logic — from SPAs on React and TypeScript to Vue/Nuxt, Bitrix and integrations.

Site stack: **Next.js**, **React**, **TypeScript**, Three.js, Framer Motion.

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
